# Flipline

A Game Off 2026 SHIFT draft about reversing gravity in a fast neon run.

Tap anywhere to start, then tap again to shift between the two rails.
Avoid the glowing barriers and see how long you can stay in motion.
Space also shifts gravity on desktop.

[Play in a browser](https://chaosmos.studio/experiments/flipline/).

Run the project with Godot 4.7.
