# Rowshift

A draft for the Game Off 2026 theme SHIFT.
Slide whole rows and columns until the colored stones match their rings.

Run with Godot 4.7:

```sh
godot --path .
```

Click or tap the arrows around the board.
Z undoes a move and R restarts the board.

The first draft tests whether moving several stones with one shift creates useful choices.
See [PLAN.md](PLAN.md) for the M0 question.
