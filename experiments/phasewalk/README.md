# Phasewalk

A draft for the Game Off 2026 theme SHIFT.
Cross each board by moving between two versions of the same room.
[Play in a browser](https://chaosmos.studio/experiments/phasewalk/).

Run with Godot 4.7:

```sh
godot --path .
```

Arrow keys move.
Space or Shift changes reality.
R retries the board.
The on-screen controls support mouse and touch.

The first draft tests the timing of a limited reality shift.
See [PLAN.md](PLAN.md) for the M0 question.
