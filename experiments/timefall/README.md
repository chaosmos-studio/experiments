# Timefall

A Game Off 2026 SHIFT draft about falling fast and shifting into slow time.

Drag to steer through the gaps.
Tap SHIFT TIME when you need a moment to line up the next gate.
Slow time spends charge that returns during normal flight.

[Play in a browser](https://chaosmos.studio/experiments/timefall/).

Run the project with Godot 4.7.
