- [Hinge Grove](hinge-grove/), [play](https://chaosmos.studio/experiments/hinge-grove/)

- [Handover](handover/), a Game Off 2026 draft about caretakers sharing a greenhouse shift. [Play](https://chaosmos.studio/experiments/handover/)
- [Phasewalk](phasewalk/), a Game Off 2026 draft about switching realities. [Play](https://chaosmos.studio/experiments/phasewalk/)
- [Rowshift](rowshift/), a Game Off 2026 draft about sliding whole lines. [Play](https://chaosmos.studio/experiments/rowshift/)
- [Flipline](flipline/), a Game Off 2026 draft about reversing gravity in motion. [Play](https://chaosmos.studio/experiments/flipline/)
- [Timefall](timefall/), a Game Off 2026 draft about steering through gates with slow time. [Play](https://chaosmos.studio/experiments/timefall/)

Each directory is a standalone Godot project.
