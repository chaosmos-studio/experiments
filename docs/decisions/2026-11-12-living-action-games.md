# Living action games: decisions

| Decision | Choice | Why | Revisit when |
| --- | --- | --- | --- |
| Scope | Three playable action slices, with different defense, stealth and momentum loops | The user wants to feel each move and test distinct concepts | One concept is selected for a full release |
| Dimension | 2D play spaces using original rendered sprites | Clear movement and combat on desktop and phone | A concept needs vertical 3D traversal |
| Language | GDScript | Godot 4.7 web exports support it | A native platform needs another language |
| Authority | Single-player | The concepts can be judged without matchmaking | Multiplayer becomes the core mechanic |
| Art | Original Blender models rendered into animated sprite atlases | One model keeps a character consistent across movement frames | A production art team takes ownership |
| Deployment | One shared Web export with three selectable modes | The user wants playable links on a phone and shared assets shorten repeat downloads | A public game repo is created |

The three modes are Brassburrow, Veilmarket and Threadrail.

## Open / deferred

- Full campaign length, progression economy and multiplayer are assumed to follow the chosen concept.
- The existing three static-image previews remain available as historical experiments.
